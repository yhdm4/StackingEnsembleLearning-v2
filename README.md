# StackingEnsembleLearning-v2

Regression stacking experiments for manuscript Sections 4.2–4.5. Six datasets, five fixed 80:20 divisions, twelve comparison methods. MSE is the primary measure; R², MAPE, MAE and RMSE are auxiliary measures.

The published results contain 990 dataset–trial–method records. Proposed has mean MSE rank **1.3000 (first)** in the training comparison and **3.8667 (second)** in the test comparison. These are descriptive rankings, not claims of pairwise statistical significance.

Records with exactly identical actual input vectors are grouped before division. Their target is the arithmetic mean, each input group receives equal weight, and first-appearance order is retained. All finite valid targets are kept. No high or low target values are removed. Non-finite data cause an explicit error.

## Four experiments

All divisions use shuffled five-fold KFold with seed 42. A trial uses four subsets for training and one for testing. Base-model OOF (out-of-fold) predictions are generated by ten-fold models: each training record is predicted by a model that did not train on that record. Standardization is fitted separately inside each base model’s training subset. Test base predictions average the ten retained models of each type.

Base models are SVM (`C=100`, RBF kernel, `gamma=auto`, `epsilon=0.1`), Random Forest (200 trees) and XGBoost (250 trees, learning rate 0.05, maximum depth 6). Model seed is 42; CPU estimators use one worker. Ridge uses alpha 1 and an unpenalized intercept. All neural networks use AdamW, betas (0.9, 0.999), epsilon 1e-8.

1. **4.2:** pure Sigmoid MLP, LR and Ridge receive standardized raw features plus OOF predictions. The Sigmoid model has no batch normalization, dropout or weight decay. Its lowest training-MSE checkpoint is retained.
2. **4.3:** compare OOF predictions alone with predictions plus raw features. Joint-input models from this release’s 4.2 are shared because all conditions match; prediction-only models are trained separately.
3. **4.4:** independently train Proposed, E2E-MLP and NN-Stacking with LeakyReLU and batch normalization, dropout 0, weight decay 0, for 3000 epochs. Retain the lowest full-training evaluation-mode MSE. ReduceLROnPlateau uses factor 0.5, patience 100, relative threshold 1e-4 and minimum learning rate 1e-6. There is no validation early stopping. LR/Ridge reuse the identical-condition fits from 4.2.
4. **4.5:** each neural method selects its own regularization and epoch within each training pool. Reserve 20% of the 80% pool for validation: approximately 64% fitting, 16% validation, 20% testing. Split seed is 20261014 plus the zero-based trial index. Rebuild preprocessing and OOF models using the fitting portion only. After selection, start a new network on the full 80% pool for the selected best epoch, retaining that endpoint. The neural weights differ from 4.4. Fixed non-neural models can be shared across 4.4 and 4.5.

NN-Stacking maps raw features to three sample-dependent, unconstrained weights and one correction, returning `sum(theta_j(x) * p_j) + phi(x)`. Convex-Stacking fits three constant nonnegative weights summing to one, without raw features, intercept or correction. Proposed maps the concatenated raw features and predictions directly to the target.

### Validation selection in 4.5

Hidden widths, learning rate and batch size are fixed per dataset. Six combinations were sampled without replacement, with seed 20261014, from the independent dropout grid `[0, 0.1, 0.2, 0.3, 0.4]` and weight-decay grid `[0, 1e-6, 1e-4, 1e-3]`. This is a six-candidate search, not an exhaustive search over all 20 combinations.

| Candidate | Dropout | Weight decay |
|---|---:|---:|
| C01 | 0.4 | 1e-6 |
| C02 | 0.1 | 1e-6 |
| C03 | 0.1 | 0 |
| C04 | 0.3 | 1e-3 |
| C05 | 0.2 | 1e-4 |
| C06 | 0.4 | 0 |

Each candidate runs at most 3000 epochs and evaluates original-unit validation MSE every epoch. Early stopping becomes eligible at epoch 50 and requires 50 consecutive epochs without relative improvement of at least 1e-4. The saved best epoch is the absolute validation-MSE minimum and may be earlier than 50. For candidates within 0.1% of the minimum MSE, ties use fewer parameters, shorter best epoch and candidate ID. No learning-rate scheduler is used. The three neural methods share candidate lists and validation rows, but select independently.

There are 540 candidate fits and 90 final neural refits in 4.5. Candidate weights are not kept after selection; final models are retained in the local run cache. The published `paper45_selected_parameters.csv` contains all 90 final configurations and refit epochs. `all_neural_parameters.csv` includes 4.4 and 4.5 (180 rows).

## Metrics and statistics

Each dataset’s MSE, R², MAPE, MAE and RMSE are computed after inverse transformation and reported as five-trial mean and sample SD. MAPE is a percentage with a denominator floor of 1e-8. `MSELoss` remains in the machine-readable records as an implementation check on the standardized target scale.

Only MSE determines ranks: rank the twelve methods within each trial and dataset, average the five ranks for a dataset, then average equally across six datasets. Ties receive average ranks within trials and the minimum position when ordering final mean ranks. A mean rank and its final position are different quantities. Raw errors from differently scaled datasets are not averaged together.

Friedman tests rank five-trial mean MSEs within each of six dataset blocks. Four omnibus P-values are jointly Holm-adjusted. There are 999999 Monte Carlo permutations with a plus-one correction, except cases calculated exactly. Kendall W describes agreement among the five MSE rankings per dataset; its 24 conditional P-values form a separate Holm family and remain exploratory because training sets overlap. An omnibus method difference does not prove a Proposed-versus-every-baseline advantage.

## Reproduction

Recorded environment: Python 3.11.9, NumPy 1.26.4, pandas 2.0.3, scikit-learn 1.5.0, XGBoost 2.0.3, PyTorch 2.0.1 with CUDA 11.8, joblib 1.4.2, Matplotlib 3.7.2, SciPy 1.16.2. GPU training is used when available; CPU execution is supported. Install PyTorch appropriate to your platform and the remaining packages with pip.

```bash
# Full four-experiment workflow; defaults to a separate results/reproduced directory.
python main.py

# Training only, then freeze models, test, and summarize in distinct stages.
python main.py --stage train --output results/reproduced
python main.py --stage freeze --output results/reproduced
python main.py --stage test --output results/reproduced
python main.py --stage summarize --output results/reproduced

# A small training request; it does not start the global test stage.
python main.py --stage train --dataset wine_quality_white --fold 0 --output results/white_trial

# Recompute statistics and redraw figures from the published fold records and curves.
python main.py --stage summarize --output results
```

The four original entry files also accept the shared `--dataset`, `--fold`, `--output` and `--stage` arguments. `train_4_1.py` runs 4.2; `ablation_4_2.py` runs 4.3; `train_4_3.py` runs the 4.4 training comparison. The recommended `main.py` workflow prepares all final models before 4.5 testing.

All 30 training tasks must finish before the final-model freeze gate permits testing. Cached protocols record code, data and configuration hashes and reject incompatible reuse. Source edits require a new output directory. Large model caches and intermediate candidate weights are excluded from the repository.

The supplied result records originate from the completed experiment on 2026-10-16. Its verification independently checked 5940 final metric values, 540 validation-MSE records and 240 neural-model curves, with no failed candidates. The release reorganizes entry points and removes inactive legacy processing; it does not claim a second complete training run of the packaged code.
